# Frontend AI Capstone

My capstone project for the FlyRank Frontend AI Engineering track.

## About

This repository will contain my frontend capstone project, developed throughout the internship using AI-assisted development.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Git and GitHub

## Development Status and Setup

The initial environment setup is complete. The `settings-form/` directory contains the React, TypeScript, and Vite application.

To run it locally:

1. Open a terminal in `settings-form/`.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` and open the local URL printed by Vite.

Run `npm run typecheck`, `npm run lint`, and `npm test` from `settings-form/` to check the code.
