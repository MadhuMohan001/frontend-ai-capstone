# Project Context

This is my capstone project for the
FlyRank Frontend AI Engineering track.

## Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Git and GitHub

## Coding Conventions

- Use functional React components.
- Use TypeScript for type safety.
- Follow reusable component principles.
- Use meaningful variable and function names.
- Keep components small and maintainable.
- Avoid unnecessary code duplication.
- Follow proper folder organization.
- Write accessible HTML and semantic markup.

## AI Development Guidelines

- Understand the task before modifying files.
- Explain the implementation approach.
- Prefer simple and maintainable solutions.
- Do not introduce unnecessary dependencies.
- Explain important code changes.
- Do not overwrite existing functionality without
  understanding its purpose.
- Ask before making destructive changes.

## Git Conventions

Follow Conventional Commits.

Examples:
- feat: add new feature
- fix: resolve a bug
- docs: update documentation
- chore: update configuration
- refactor: improve code structure

## Project Development Rules

1. All form inputs must be controlled React inputs.

2. Every form input must have an associated
   accessible label.

3. All user inputs must be validated before
   successful submission.

4. Every important form interaction must have
   automated test coverage.

5. Do not install unnecessary dependencies
   without checking existing packages.
