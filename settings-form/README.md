# Forma Account Settings

A responsive React and TypeScript account settings form built with Vite.

## Features

- Edit a name and email address.
- Set and confirm a password, with required-field, email, and password-match validation.
- Toggle product update notifications.
- Preview the name and email in the account summary as they are entered.
- Submit the form and receive an accessible confirmation.

This is a frontend demo: settings are held in the page state and are not sent to a server or persisted after reloading.

## Getting Started

From this directory, install dependencies and start the development server:

```sh
npm install
npm run dev
```

## Checks

```sh
npm run typecheck
npm run lint
npm test
npm run build
```
